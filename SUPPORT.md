# Support

Use GitHub Issues for bugs, compatibility problems, and focused feature requests:

https://github.com/Serbyte-Development/compress-image/issues

When reporting a compression problem, include:

- VS Code or Cursor version.
- Operating system and CPU architecture.
- Whether the file is local, Remote SSH, WSL, or inside a dev container.
- Image format and whether it is animated.
- Original and resulting file sizes, if compression completed.
- A minimal image that reproduces the problem, when the asset is safe to share.

Compress Image supports local filesystem workspaces. Virtual/browser workspaces are not supported because optimization uses bundled native executables.
